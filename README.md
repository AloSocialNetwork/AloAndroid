# Alo Android

Клиент социальной сети и мессенджера «ало» для Android. Это нативное приложение на Kotlin и Jetpack Compose,
которое работает с тем же сервером, что и сайт «ало» и приложение для iPhone
([AloSocialNetwork/AloiOS](https://github.com/AloSocialNetwork/AloiOS)).

Готовая сборка: https://test.xn--80awj.online/downloads/android/latest.apk (Android 7.0 и новее, 64-битные телефоны).
Установленное приложение обновляется само.

## Что умеет

- **Лента:** посты с текстом, фото и видео, лайки, комментарии, репосты.
- **Истории:** съёмка, публикация и просмотр.
- **Сообщения:** личные и групповые чаты, каналы, реакции, ответы, пересылка, редактирование, вложения.
- **Голосовые и видеокружки:** запись, отправка и воспроизведение прямо в чате.
- **Секретные чаты:** сквозное шифрование на libsignal, сообщения видны только участникам.
- **Модерация:** жалобы на контент и панель для команды модераторов.
- **Звонки:** аудио- и видеозвонки, групповые видеочаты, демонстрация экрана (WebRTC, LiveKit).
- **Профили и поиск:** подписки, заявки в друзья, настройки приватности, поиск людей и каналов.
- **Уведомления:** push-уведомления через Firebase Cloud Messaging.
- **Вход:** по email, по коду, по passkey и по QR-коду с другого устройства.
- **Геопозиция:** выбор точки на карте MapLibre.

## Технологии

- Kotlin, Jetpack Compose
- libsignal — сквозное шифрование
- WebRTC и LiveKit — звонки
- CameraX — камера, истории и видеокружки
- Firebase Cloud Messaging — push-уведомления
- MapLibre Native — карты
