# Third-party notices and asset provenance

## Alo original chat wallpaper

`app/src/main/res/drawable-nodpi/alo_chat_pattern.png` is generated locally
from `design/AloChatWallpaper.svg`.

The vector artwork is an original Alo composition of abstract network routes,
orbits and cards. It does not contain Telegram artwork, Telegram source code or
other third-party pattern material. It is covered by the Alo project license.

## MapLibre Native

## Default map style and data

The default development map style is served by OpenFreeMap. Map data is
attributed to OpenStreetMap contributors and is subject to the Open Database
License. Alo keeps the map attribution controls visible in the picker.
